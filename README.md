# TVBox 3

Домашний медиацентр: ПК у телевизора (**ТВ-клиент**) + пульт в браузере / PWA / Android (**пульт**) + лёгкий **сервер-маршрутизатор** на VPS.

```
packages/shared      общие типы, события Socket.io, роли, парсер имён торрентов
apps/backend         сервер: Google-вход, сессии, QR-привязка, Socket.io-хаб, WebRTC-сигналинг, раздача пульта
apps/remote-client   пульт: React + Vite + PWA + Capacitor (APK)
apps/tv-client       ТВ-клиент: Electron (плеер, YouTube, торренты, TMDb, SQLite, ffmpeg, экран ожидания)
deploy/              Docker Compose (backend + Caddy HTTPS + coturn), скрипт установки на VPS
```

Сервер не хранит медиа и не скачивает торренты: он только пересылает команды между пультом и телевизором,
помогает установить P2P-трансляцию (WebRTC) и отдаёт веб-пульт. Работает в ~60 МБ ОЗУ.

## Как всё связано

1. **Пульт** — `https://tv.nemnogovova.com`. Вход по **логину и паролю** или через Google (если на сервере
   задан `GOOGLE_CLIENT_ID`). Владелец — `nemnogovova@gmail.com` (или `OWNER_USERNAME`; на сервере без
   Google владельцем становится первый зарегистрированный). Новые пользователи регистрируются сами и ждут
   одобрения владельца («Настройки → Доступ»); Google-адреса из приглашений входят сразу.
   В «Настройки → Аккаунт и сервисы» можно задать/сменить пароль, привязать или отвязать Google.
2. **Телевизор** при первом запуске показывает QR-код и 6-значный код. Наведите камеру телефона,
   войдите владельцем и нажмите «Подключить». Больше ничего вводить не нужно.
3. **Android-приложение** входит по логину и паролю прямо в приложении (или через Google в браузере).

## ТВ-клиент (Windows)

Сборка: дважды кликнуть `build-windows.cmd`. Скрипт повышает версию (3.0.0 → 3.0.1), собирает установщик
(`apps/tv-client/release/TVBox-Setup-x.y.z.exe`) и APK (`release/TVBox-Remote-x.y.z.apk`) и **публикует их на сервер**:
в веб-пульте появляются кнопки «Скачать для Android / Windows», а телевизор и телефон видят обновление
(«Настройки → YouTube и обновления ТВ → Обновить», «Настройки → Приложения → Обновить»). ТВ скачивает
установщик, ставит его без вопросов и перезапускается. Для публикации нужен файл `.release-token` —
его сохраняет `deploy.ps1` после деплоя. Ключи: `build-windows.cmd nobump`, `build-windows.cmd nopublish`.

Возможности:
- Плеер: локальные файлы, торренты во время загрузки, прямые ссылки, YouTube, музыка.
- YouTube открывается как обычная страница youtube.com (а не встроенный плеер), поэтому играют и ролики
  «запрещённые для воспроизведения на других сайтах». Можно войти в аккаунт YouTube на ТВ
  («Настройки → YouTube и обновления ТВ → Войти на ТВ», ввод с клавиатуры у телевизора) — подписки, Premium, 18+.
- MKV/AVI с AC3/DTS-звуком и т.п. воспроизводятся через встроенный ffmpeg на лету (видео копируется без
  перекодирования, звук → AAC с выравниванием по видео — без рассинхрона к концу серии), перемотка работает.
  Выбор озвучки и субтитров (встроенных и .srt рядом с файлом) с пульта — длинные списки открываются
  в прокручиваемом окне с поиском.
- Музыка: Jellyfin, Navidrome и любые Subsonic-серверы. Подключаются в пульте («Музыка»), альбомы, исполнители,
  плейлисты, поиск; очередь, перемешивание, повтор, предыдущий/следующий трек, перемотка. Прослушанные треки
  кешируются на ТВ-компьютере (`%USERPROFILE%\.tvbox\music-cache`, лимит настраивается, старые удаляются сами).
- Прогресс просмотра сохраняется каждые 5 секунд, фильмы и сериалы продолжаются с места остановки,
  следующая серия включается автоматически.
- Торренты (WebTorrent): последовательная загрузка, «Смотреть сейчас» с первых процентов,
  после 100% раздача останавливается (leech-only), файл попадает в медиатеку.
- TMDb: обложки, описания, рейтинги, серии и сезоны. Ключ вводится в пульте: «Настройки → Настройки ТВ-клиента».
- Экран ожидания: часы, погода, «Продолжить просмотр», «Недавно добавленные», QR пульта,
  виджеты по API и свои HTML/CSS/JS-виджеты (в изолированном iframe), заставка: часы, обложки медиатеки,
  чёрный экран или **свои фото и видео** — по ссылкам или загруженные с телефона/компьютера, со сменой по таймеру,
  перемешиванием и часами поверх.
- Громкость системы Windows, сон / перезагрузка / выключение ПК с пульта (только владелец).
- Клавиатура/пульт ТВ у компьютера: пробел/Enter — пауза, ←/→ — перемотка, ↑/↓ — громкость, Esc — стоп, F — экран.
  `Ctrl+Shift+Q` — выход.

Данные: `%USERPROFILE%\.tvbox` (config.json, tvbox.sqlite). Загрузки по умолчанию — `Видео\TVBox`.

## Пульт

- Телефон: нижняя навигация (Пульт, Медиатека, Музыка, Загрузки, Экран, Настройки), крупные кнопки,
  мгновенный отклик ползунков, мгновенное переподключение при возврате в приложение.
- Компьютер: двухпанельный режим (слева медиатека/файлы/загрузки, справа постоянный пульт и очередь),
  горячие клавиши `Пробел`, `←/→`, `↑/↓`, `M`, `F`; перетаскивание `.torrent` или видео/фото в окно;
  `Ctrl+V` ссылки YouTube/magnet в любом месте окна сразу предлагает запустить её на ТВ.
- Трансляция по WebRTC: файл с устройства (с локальными кнопками перемотки), фото без потерь,
  экран (на ПК), камера. Через сервер идёт только сигналинг; при «строгом» NAT поток пойдёт через
  TURN (coturn на VPS) с ограничением 4 Мбит/с на сессию, чтобы не съесть 500 ГБ трафика.
- Владелец: гости, «режим диктатора», питание ТВ-ПК, отвязка ТВ, настройки ТВ-клиента, редактор экрана ожидания.

### Android APK

```
npm run apk
```
Нужен Android Studio (SDK + JDK). Скрипт собирает пульт, синхронизирует Capacitor, кладёт нативный код из
`apps/remote-client/native-android` (кнопки громкости → громкость ТВ, открытие `magnet:` и `.torrent`,
«Поделиться» ссылкой YouTube в TVBox) и собирает `release/TVBox-Remote-x.y.z.apk` — release-сборку,
подписанную собственным ключом `.android-release.jks` (создаётся при первой сборке, пароль в `.android-release.json`).
**Сохраните оба файла**: обновления APK ставятся поверх только с тем же ключом.

**Управление при выключенном экране**: приложение держит уведомление с кнопками «назад / пауза / далее»
(они же на экране блокировки), а кнопки громкости телефона меняют громкость ТВ даже при погашенном экране.
Работает через HTTPS-запросы к серверу, поэтому не зависит от «уснувшего» WebView. Выключается
в «Настройки → Подключение» или кнопкой «Отключить» в уведомлении.

## Сервер

Деплой с Windows одной командой (спросит пароль root один раз):

```
powershell -ExecutionPolicy Bypass -File .\deploy.ps1
```

Скрипт отправляет готовый бандл `deploy/tvbox-server.tgz` и запускает `deploy/server-setup.sh`:
ставит Docker (если нет), создаёт swap, генерирует `/opt/tvbox/.env` (секреты сессий и TURN),
поднимает `backend` + `caddy` (автоматический HTTPS для `tv.nemnogovova.com`) + `coturn`.
`-Rebuild` пересобирает бандл из исходников. В конце деплоя токен публикации сборок сохраняется в `.release-token`.

Переменные — см. `apps/backend/.env.example`.

npm run dev:backend # :3000
