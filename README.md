## Зачем

Вы подключили старый (или не очень) ПК к телевизору. Вам нужен один пульт на телефоне,
который умеет всё: запускать фильмы и сериалы, торренты, YouTube, музыку — и чтобы
это просто работало, без танцев с бубном.

**TVBox** — это именно это:

| Компонент | Что делает | Где живёт |
|-----------|-----------|-----------|
| **🖥 ТВ-клиент** | Плеер, YouTube TV, торренты, музыка, запуск программ и игр | Windows (Electron) |
| **📱 Пульт** | Управление, каталог, медиатека, тачпад, загрузки, настройки | Браузер / PWA / Android APK |
| **☁️ Сервер** | Связывает пульт и ТВ, HTTPS, WebRTC-сигналинг | VPS (Docker, ~60 МБ ОЗУ) |

> Сервер **не хранит** ваши файлы и **не скачивает** торренты — он только пересылает команды.
> Всё тяжёлое происходит на вашем ПК у телевизора.

## ✨ Возможности

### 🎬 Плеер — играет всё

<img src="docs/screenshots/remote-desktop.jpg" width="500" alt="Плеер — пульт с играющим сериалом" align="right"/>

- **Локальные файлы** — MKV, AVI, MP4 и любые форматы с любыми кодеками
- **MKV с AC3/DTS** — звук перекодируется на лету через ffmpeg, видео копируется без потерь. Перемотка по опорным кадрам — **без рассинхрона**
- **Выбор озвучки и субтитров** с пульта — встроенные дорожки и внешние `.srt`. Длинные списки открываются в окне с поиском; смена озвучки не сбрасывает ни картинку, ни субтитры
- **HEVC / x265 на любом ПК**: если видеокарта такой формат не показывает, видео перекодируется на лету; не успевает компьютер — TVBox сам переходит на облегчённое качество 720p
- **Прогресс сохраняется** каждые 5 секунд. Фильм продолжится с того же места, следующая серия включится сама — даже если сезон ещё качается
- **Прямые ссылки** — вставьте URL видеофайла и смотрите

<br clear="both"/>

### 🍿 Каталог — найти и сразу смотреть

- **Витрина как в онлайн-кинотеатре**: тренды дня, новинки, лучшие фильмы и сериалы, мультфильмы, аниме, российское кино, подборки по жанрам
- **«Рекомендуем вам»** — подборка по тому, что вы уже смотрели
- Фильтры по жанру, годам и рейтингу, поиск по названию
- Карточка фильма: описание, актёры, режиссёр, сезоны, похожее, **трейлер одним нажатием на ТВ**
- **«Смотреть»** — TVBox сам опрашивает трекеры и ставит первым лучший вариант: правильное название и год, русская озвучка, 1080p, живые сиды, без экранок
- «Смотреть сейчас» — видео стартует через минуту, ещё до конца загрузки; «Скачать» — файл появится в медиатеке с обложкой
- Поиск раздач идёт через ваш **Jackett или Prowlarr**: установите любой на ПК с TVBox — он найдётся автоматически

### 🔴 YouTube — как на Smart TV, только без рекламы

- **Настоящий YouTube для телевизоров**: главная, подписки, плейлисты, «Смотреть позже», история, поиск — управление стрелками с пульта
- **Реклама вырезается до показа** (как в Brave / uBlock): рекламные блоки удаляются из ответов YouTube, рекламные серверы заблокированы
- **Аккаунт — кодом с телефона**: пульт показывает код, открываете yt.be/activate, подтверждаете — на ТВ ничего печатать не надо
- Открывается плавно, без белых вспышек и прыжков в полный экран; повторное открытие — мгновенно
- **Ссылки на плейлисты** (и «видео из плейлиста») играют весь плейлист подряд
- «Главная» на пульте возвращает на главную YouTube из любого места, даже из ролика
- **Пульт и клавиатура работают внутри YouTube**: стрелки, OK и «Назад» доходят до страницы, даже если окно TVBox не в фокусе
- Вход в гостевом режиме одним нажатием — без экрана «Начать»; если YouTube не открылся, пульт показывает настоящую причину
- Ссылку на ролик можно просто вставить на пульте — видео сразу на ТВ

### 🎮 Программы и игры — Jackbox с дивана

- Пульт показывает **все программы с ПК**: меню «Пуск», Microsoft Store, **библиотека Steam** — с иконками
- Можно добавить **любой .exe**, даже если его нет в реестре: обзор папок ПК прямо с телефона
- Запуск — **сразу на весь экран**, TVBox уступает экран и возвращается сам, когда игру закрыли
- Открытые окна: показать, развернуть, свернуть, закрыть (а зависшее — завершить)
- **Тачпад на телефоне**: курсор с ускорением, тап — клик, два пальца — прокрутка и правый клик, удержание — перетаскивание; клавиатура и Esc / Enter / Alt+Tab / F11

### 🧲 Торренты — смотрите сразу

- **WebTorrent** с последовательной загрузкой — начните смотреть с первых процентов
- Перетащите `.torrent` или вставьте `magnet:` — всё
- После скачивания файл попадает в медиатеку с обложками TMDb

### 🎵 Музыка — ваши серверы

<img src="docs/screenshots/music-mobile.jpg" width="230" alt="Музыка — альбомы с обложками" align="right"/>

- **Jellyfin**, **Navidrome** и любые **Subsonic**-совместимые серверы
- Альбомы, исполнители, плейлисты, поиск
- Очередь, перемешивание, повтор, перемотка
- Кеш прослушанных треков на ПК (лимит настраивается, старые удаляются сами)

### 📡 Трансляция (WebRTC)

- Транслируйте **файл с телефона**, фото, экран ПК или камеру — прямо на ТВ
- P2P: через сервер идёт только сигналинг
- За «строгим» NAT поток пойдёт через встроенный TURN (ограничение: 4 Мбит/с на сессию)

### 🖼 Экран ожидания

- Часы, погода, «Продолжить просмотр», «Недавно добавленные», QR пульта
- Кастомные виджеты по API или HTML/CSS/JS (в изолированном iframe)
- Заставка: часы, обложки медиатеки, чёрный экран или **свои фото, видео и ролики YouTube** (и целые плейлисты) — по ссылкам или загруженные с телефона
- Кадры **плавно перетекают** друг в друга; следующий заранее загружен, а большие фото с камеры ТВ сам уменьшает до размера экрана — смена без задержек и рывков
- На пульте видны **превью** всех картинок и видео заставки
- **Фон главного экрана**: кадр из последнего фильма, своя картинка или без картинки

### 🖱 Курсор не мешает

- Указатель мыши прячется через пару секунд покоя — и над TVBox, и поверх YouTube

### 🏠 Дома — один сервер на много семей

- Сервер обслуживает **сколько угодно изолированных «домов»**: дом — это один телевизор и люди, которым владелец разрешил им пользоваться
- Дома **не видят друг друга**: что играет, медиатека, торренты, команды пульта, трансляция, список людей — всё остаётся внутри своего дома
- Свой телевизор подключается по QR-коду: кто подтвердил код, тот и владелец его дома (пароль от аккаунта на ТВ вводить не нужно — для этого и QR)
- Позвать людей — **ссылка-приглашение** («Настройки → Дом → Пригласить»): по ней входят или регистрируются и сразу становятся гостями, без одобрения. Ссылку можно заменить новой — старая перестанет работать
- Можно пустить и по Google-почте, убрать человека из дома, сделать совладельцем, переименовать или удалить дом
- Один аккаунт — в нескольких домах (свой ТВ и ТВ друзей), переключение в настройках; второй телевизор можно завести отдельным домом
- Гости с ограниченными правами (запуск игр — можно, тачпад — только владелец), «режим диктатора»

### 👥 Аккаунты и администратор сервера

- Вход по **логину/паролю** или через **Google**, привязка и отвязка Google в настройках
- **Администратор сервера** (`OWNER_EMAIL` / `OWNER_USERNAME` из `.env`, без них — первый аккаунт) выбирает режим регистрации: *открыта* / *по одобрению* (по умолчанию) / *закрыта* (только по приглашениям), одобряет новые аккаунты, видит все дома и аккаунты. Чужие телевизоры и их содержимое он не видит и не управляет ими
- При обновлении с 3.1 и раньше всё переезжает в один дом само: телевизор, гости и приглашения сохраняются, перепривязывать ничего не нужно (старый `store.json` остаётся рядом как `store.json.v1.bak`)

### 🔄 Автообновление

- `build-windows.cmd` — **один клик**: повышает версию, собирает установщик Windows + APK Android, публикует на сервер
- ТВ-клиент скачивает обновление и ставит его сам, как только ничего не играет
- Если ТВ отстал от сервера, пульт показывает плашку **«На телевизоре старый TVBox» → «Обновить ТВ»**; несовместимые версии не делают вид, что всё работает
- Телефон видит обновление в настройках

### 🩺 Диагностика

- Журнал ТВ-клиента пишется в `%USERPROFILE%\.tvbox\logs\tvbox.log` (ротация по 2 МБ)
- Там видно причину, если не открылся YouTube, не запустилась программа или не работает тачпад (PowerShell-помощник)

```
     ┌────────▼────────┐        ┌─────────▼────────┐
```

## 🚀 Быстрый старт

### 1. Разверните сервер (одна команда)

```powershell
# С Windows — спросит пароль root один раз
powershell -ExecutionPolicy Bypass -File .\deploy.ps1
```

Скрипт сам поставит Docker, создаст swap, настроит HTTPS (Caddy + Let's Encrypt),
поднимет backend + coturn. Готово.

### 2. Соберите и опубликуйте

```
build-windows.cmd
```

Дважды кликните — скрипт:
1. Повысит версию
2. Прогонит тесты
3. Соберёт установщик Windows (.exe) и APK Android
4. Опубликует оба на сервер — кнопки скачивания появятся в пульте

> Ключи: `build-windows.cmd nobump` (не повышать версию), `build-windows.cmd nopublish` (не публиковать)

### 3. Подключите ТВ

<img src="docs/screenshots/login-mobile.jpg" width="230" alt="Экран входа с Google и логин/пароль" align="right"/>

1. Установите TVBox на ПК у телевизора
2. На экране появится QR-код и 6-значный код
3. Откройте пульт на телефоне, войдите (или зарегистрируйтесь), отсканируйте QR
4. Готово — телевизор в вашем доме. Остальных зовите ссылкой-приглашением из настроек

## 📦 Android APK

```bash
npm run apk
```

Нужен Android Studio (SDK + JDK). Скрипт соберёт release-APK, подписанный вашим ключом.

**Что умеет нативное приложение сверх PWA:**
- 🔊 Кнопки громкости телефона → громкость ТВ (даже с выключенным экраном)
- 🔔 Уведомление с кнопками управления на экране блокировки
- 🧲 Открытие `magnet:` ссылок и `.torrent` файлов прямо в TVBox
- 📤 «Поделиться» ссылкой YouTube из любого приложения → сразу на ТВ

> ⚠️ При первой сборке создаются `.android-release.jks` и `.android-release.json` — **сохраните их!**
> Обновления APK ставятся поверх только с тем же ключом подписи.

## 🛠 Разработка

```bash
npm install
npm test              # 98 тестов: изоляция домов, миграция, приглашения, роли, сокеты, авторизация, медиатека, разбор раздач, каталог, поиск по трекерам…

npm run dev:backend    # :3000
npm run dev:remote     # :5173 (проксирует API на :3000)
npm run dev:tv         # Electron в dev-режиме
```

## 🔒 Безопасность

- Пароли хранятся как **scrypt**-хеши — не в открытом виде
- Сервер работает только через **HTTPS** (Caddy + Let's Encrypt, автопродление)
- WebRTC-сигналинг и управление ТВ — только для авторизованных пользователей и только внутри своего дома: сервер проверяет дом на каждой команде, трансляции и рассылке состояния
- Токен телевизора привязан к дому: «Отвязать телевизор» или удаление дома сразу его отключают
- TURN-сервер с аутентификацией и ограничением полосы (4 Мбит/с на сессию)
- APK подписан собственным ключом (v1 + v2 подписи)
- Контейнеры ограничены по памяти и числу процессов
